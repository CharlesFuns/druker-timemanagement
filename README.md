# 有效时间

基于德鲁克时间管理思想的个人时间管理与任务记录工具。

它可以真实记录目标、任务、日程、任务计时、时间片段、手动补录、24 小时时间轴、日看板和每日觉醒日记。数据保存在 Supabase 云端，适合部署到 Vercel 使用。

## 已完成的 MVP 能力

- 登录 / 注册
- 自动创建四类默认目标
- 创建目标，并支持启用 / 停用
- 创建任务，并绑定目标
- 任务开始、暂停、继续、完成
- 一个任务支持多个真实时间片段
- 支持多个任务同时执行
- 创建单次日程，并自动进入时间记录
- 手动补录任务 / 日程 / 临时事项
- 修改或删除已有时间记录
- 24 小时时间轴，支持并行时间块
- 日维度数据看板
- 每日复盘与觉醒日记

## 本地配置

1. 在 Supabase 创建项目。
2. 打开 Supabase 的 SQL Editor，运行 `supabase/schema.sql`。
3. 复制 `.env.example` 为 `.env.local`。
4. 填入 Supabase 的项目地址和 anon key。
5. 安装依赖并启动：

```bash
npm install
npm run dev
```

如果 Supabase 开启了邮箱验证，注册后需要先完成邮箱验证再登录。个人使用时，也可以在 Supabase 后台关闭邮箱验证。

## 部署到 Vercel

1. 把项目推送到 Git 仓库。
2. 在 Vercel 导入项目。
3. 在 Vercel 的环境变量里添加：
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. 部署即可。

## 验收建议

- 新建目标，创建任务，开始计时。
- 暂停任务后确认累计耗时不再增加。
- 继续任务后确认生成新的时间片段。
- 同时启动两个任务，确认时间轴并行展示。
- 手动补录一条记录，确认日看板同步变化。
- 填写每日复盘，刷新后确认内容仍然存在。
